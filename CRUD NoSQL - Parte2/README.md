# CRUD NoSQL - Parte 2

Esta pasta será utilizada para o desenvolvimento da Parte 2 do Trabalho Prático de Engenharia de Dados.

A Parte 2 será dedicada ao CRUD utilizando banco de dados NoSQL, conforme definição do trabalho.

## Execução:

```powershell
$env:SPRING_DATA_MONGODB_URI=<URI>
# Modifique a URI de acordo com a conexão
```

### Executando o backend

```powershell
cd "CRUD NoSQL - Parte2\backend"
mvn clean install
mvn spring-boot:run
```
